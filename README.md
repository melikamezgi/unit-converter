# 🔄 Unit Converter

A simple unit converter made with Python.

## Features
- Convert Celsius and Fahrenheit
- Convert Kilograms and Grams
- Convert Meters and Centimeters
- Easy menu to choose conversions
- Multiple conversions in one run

## How to Run

```bash
unit_converter.py
```

## Technologies
- Python 3

## About
This is a beginner Python project made to practice loops, conditions, variables, and calculations.
